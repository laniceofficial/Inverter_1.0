20khz无法跑满，是否是导致波形不对的问题？
10khz 波形正常一点，但有高频响声，电压过低

- test1
只改动 开关频率-》8khz 载波为10khz
测试结果：响声频率更高，损耗电压更低

- test2
载波频率不变10khz ，改变开关频率为20khz
测试结果：无响声，发现电压幅值受Uref影响 ； U=0.5V，Udc为15v时，输出有效值为10v
但Uref较大时，波形出现谐波影响

- test3
载波频率提高为15khz ，开关频率为20khz
测试结果：无响声，波形更丑了
- test4
载波频率提高为20khz ，开关频率为20khz
测试结果：无响声，波形较丑，已拍照，频率下降，20khz无法跑满
- test5
载波频率提高为20khz，但修改计算频率为15khz ，开关频率为20khz
测试结果：无响声，波形较丑，已拍照，频率为69hz
- test6
载波频率提高为20khz，但修改计算频率为17khz ，开关频率为20khz
测试结果：无响声，波形较丑，已拍照，频率为52hz
- test7
载波频率提高为20khz，但修改计算频率为18khz ，开关频率为20khz
测试结果：无响声，波形较丑，已拍照，频率为50hz
- test8
载波频率提高为25khz，但修改计算频率为23khz ，开关频率为20khz
测试结果：波形变”脏“，导致示波器频率有点难以计算，计算25hz也不行


# 总结
Uref影响波形幅值，开关频率影响波形稳定性
