### 单相逆变

hrtim 上升计数
adc采样：采样点应选在周期的3/4处。考虑到ADC采样窗口的持续时间，需要提前半个采样时间触发ADC，使采样窗口的中点对准3/4周期点。
开关频率/载波频率100khz，HRTIM计数周期值 PERIOD=27200
adc时钟：170MHz/4 = 42.5MHz，周期 = 1/42.5MHz ≈ 23.5294 ns。
将这个时间转换为HRTIM计数值：
计数值 = 触发时间 / (T/27200) = 触发时间 _ (27200 / T) = 7.17647e-6 _ (27200 / 10e-6) = 7.17647e-6 _ 2.72e9 = 7.17647e-6 _ 2.72e9 = 19520
所以计数值约为19520。（Hrtim--compare2）

通过设置hrtim的主定时器的比较单元1和3，控制从定时器的set和reset实现相位改变
